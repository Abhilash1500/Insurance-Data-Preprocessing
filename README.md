# Insurance Data Preprocessing

## About the Project
This project focuses on data preprocessing and feature engineering using the Medical Insurance dataset.

The main objective is to clean, transform, and prepare raw data for further Machine Learning tasks.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy
- Jupyter Notebook

## Topics Covered

1. Exploratory Data Analysis (EDA)
2. Data Cleaning
3. Handling Missing Values
4. Categorical Encoding
5. One-Hot Encoding
6. Feature Engineering
7. BMI Categorization
8. Feature Scaling using StandardScaler
9. Pearson Correlation
10. Chi-Square Statistical Test
11. Feature Selection

## Feature Selection Techniques

- Pearson Correlation: Used to identify relationships between numerical features and insurance charges.
- Chi-Square Test: Used to examine the association between categorical features and insurance charge categories.
